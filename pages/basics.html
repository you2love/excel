2.1 数据输入

掌握数据输入是使用 Excel 的基础，Excel 2026 提供了多种便捷的数据输入方式。

基本数据输入

  • 点击单元格选中，然后直接输入数据
  • 双击单元格进入编辑模式
  • 按 Enter 键确认输入并移动到下一单元格
  • 按 Tab 键移动到右侧单元格
  • 按 Esc 键取消输入

文本输入技巧

小技巧：如果要在单元格中输入多行文本，按Alt+Enter插入换行符。

数字输入

Excel 会自动识别数字格式。输入数字时注意：

  • 小数点使用句点（.）
  • 千位分隔符会自动添加
  • 输入分数时，如输入 1/2 会被识别为日期，应输入 0 1/2

日期和时间输入

Excel 支持多种日期和时间格式：

  • 日期：2026-1-15 或 2026/1/15
  • 时间：14:30 或 2:30 PM
  • 当前日期快捷键：Ctrl+;
  • 当前时间快捷键：Ctrl+Shift+;
Ctrl + ; 输入当前日期
Ctrl + Shift + ; 输入当前时间
Alt + Enter 单元格内换行
Ctrl + Enter 批量填充相同内容
Ctrl + E 快速填充（Flash Fill）
F2 编辑单元格

2.2 数据编辑

学会编辑已输入的数据是 Excel 操作的重要技能。

编辑单元格内容

  1. 双击单元格进入编辑模式
  2. 或选中单元格后按 F2 键
  3. 在编辑栏中直接修改内容

清除单元格内容

右键点击单元格，选择"清除"，可以：

  • 清除全部：删除内容、格式和批注
  • 清除格式：只删除格式设置
  • 清除内容：只删除单元格内容
  • 清除批注：只删除批注

2.3 单元格选择

掌握快速选择单元格的方法可以提高工作效率。

选择单个单元格

直接点击单元格即可选中。

选择连续单元格区域

  • 点击第一个单元格，拖动到最后一个单元格
  • 点击第一个单元格，按住 Shift 键点击最后一个单元格
  • 使用键盘方向键配合 Shift 键

选择不连续单元格

按住 Ctrl 键点击多个单元格。

选择整行或整列

  • 点击行号选择整行
  • 点击列标选择整列
  • 点击工作表左上角选择全部单元格

快捷选择技巧

Ctrl + A 选择当前数据区域 Ctrl + Shift + End 选择到数据区域末尾 Ctrl + Space 选择整列 Shift + Space 选择整行 Ctrl + Shift + ↓ 选择到列末 Ctrl + Shift + → 选择到行末

2.4 移动和复制数据

移动和复制数据是日常工作中最常用的操作。

拖动移动

  1. 选中要移动的单元格或区域
  2. 将鼠标移动到选区边框
  3. 鼠标变为十字箭头后拖动到目标位置

拖动复制

操作同上，但在拖动时按住 Ctrl 键。

剪切和粘贴

  • 快捷键：Ctrl+X（剪切）、Ctrl+C（复制）、Ctrl+V（粘贴）
  • 右键菜单：剪切、复制、粘贴

粘贴选项

粘贴时 Excel 提供多种粘贴选项：

选项 说明 快捷键
粘贴 常规粘贴，保留所有格式 Ctrl+V
值 只粘贴数值，不保留公式 Ctrl+Alt+V, V
格式 只粘贴格式设置 Ctrl+Alt+V, T
公式 只粘贴公式 Ctrl+Alt+V, F
转置 行列互换 Ctrl+Alt+V, E
高级技巧：粘贴后出现的"粘贴选项"按钮提供更多选择性粘贴选项，如图片、链接、运算等。

Excel 的填充功能可以快速输入序列数据和复制公式。

自动填充柄

选中单元格后，右下角会出现小方块（填充柄），拖动它可以：

  • 复制数据到相邻单元格
  • 填充序列（日期、数字序列）
  • 复制公式

填充选项

拖动填充柄后，点击出现的"自动填充选项"按钮可以选择：

  • 复制单元格
  • 填充序列
  • 仅填充格式
  • 不带格式填充
  • 以天数填充
  • 以工作日填充

自定义序列

Excel 预定义了许多常用序列，你也可以创建自己的序列：

  1. 文件 > 选项 > 高级
  2. 滚动到"常规"部分
  3. 点击"编辑自定义列表"
  4. 输入你的序列，每项一行
  5. 点击"添加"完成

2.6 查找和替换

在大量数据中查找和替换内容是必备技能。

基本查找

  • 快捷键：Ctrl+F
  • 输入查找内容
  • 点击"查找全部"或"查找下一个"

高级查找选项

  • 区分大小写
  • 匹配整个单元格内容
  • 使用通配符（?表示单个字符，*表示多个字符）
  • 搜索格式

替换功能

  • 快捷键：Ctrl+H
  • 输入查找内容和替换内容
  • 选择"替换"或"全部替换"
2026 新特性：Excel 2026 引入 AI 智能查找，可以模糊匹配相似内容，大大提高查找效率。

2.7 撤销和重做

掌握撤销和重做可以避免操作失误。

  • 撤销：Ctrl+Z 或点击撤销按钮
  • 重做：Ctrl+Y 或点击重做按钮
  • Excel 默认记录最近的 100 次操作
注意：某些操作（如保存文件）无法撤销，操作前请谨慎。

2.8 工作表操作

掌握工作表的管理和组织方法。

插入工作表

  • 点击工作表标签右侧的"+"按钮
  • 右键点击工作表标签，选择"插入"
  • 快捷键：Shift+F11

删除工作表

  • 右键点击工作表标签，选择"删除"
  • 选中工作表后，开始选项卡 > 删除

重命名工作表

  • 双击工作表标签
  • 右键点击工作表标签，选择"重命名"

移动和复制工作表

  • 拖动工作表标签移动位置
  • 按住 Ctrl 键拖动可以复制工作表
  • 右键点击工作表标签，选择"移动或复制"

工作表标签颜色

右键点击工作表标签，选择"工作表标签颜色"，可以为工作表设置不同颜色以便区分。
