7.1 Excel 编程概述

Excel 提供多种编程和自动化方案，每种方案都有其适用场景。

主要编程方案

📜 VBA 宏

传统的 Excel 自动化方案，功能强大且成熟

  • 适合：复杂业务逻辑、UI 交互
  • 优势：与 Excel 深度集成
  • 局限：仅限 Windows、安全性考虑

🔌 Power Query

强大的数据连接和转换工具

  • 适合：数据清洗、ETL 流程
  • 优势：可视化操作、易上手
  • 局限：复杂逻辑受限

🐍 Python in Excel

2026 新特性 Python 直接运行在 Excel 中

  • 适合：数据分析、机器学习
  • 优势：丰富的库生态
  • 局限：需要 Microsoft 365

⚡ LAMBDA 函数

无需代码的自定义函数

  • 适合：自定义计算逻辑
  • 优势：安全、易分享
  • 局限：功能相对简单

7.2 VBA vs Python 代码对比

通过实际代码对比，了解两种方案的特点。

📜 VBA - 汇总销售数据

Sub SummarizeSales()
    Dim ws As Worksheet
    Dim lastRow As Long
    Dim i As Long
    Dim total As Double
    
    Set ws = ThisWorkbook.Sheets("Sales")
    lastRow = ws.Cells(ws.Rows.Count, "A").End(xlUp).Row
    
    total = 0
    For i = 2 To lastRow
        total = total + ws.Cells(i, "C").Value
    Next i
    
    ws.Range("C" & lastRow + 1).Value = total
    ws.Range("C" & lastRow + 1).Font.Bold = True
End Sub

🐍 Python - 同样的功能

import pandas as pd

# 读取 Excel 数据
df = pd.read_excel(
    "Sales.xlsx", 
    sheet_name="Sales"
)

# 计算总额
total = df["Amount"].sum()

# 添加总计行
total_row = pd.DataFrame({
    "Amount": [total]
}, index=["Total"])

df = pd.concat([df, total_row])

# 保存结果
df.to_excel(
    "Sales_Summary.xlsx",
    index=False
)

7.4 Power Query 入门

Power Query 是 Excel 内置的强大数据连接和转换工具。

Power Query 特点

  • 可视化操作，无需编程
  • 支持多种数据源
  • 可重复使用的查询
  • 自动刷新数据
  • M 语言支持高级定制

基本使用步骤

  1. 数据选项卡 > 获取数据
  2. 选择数据源（Excel、CSV、数据库、Web 等）
  3. 在 Power Query 编辑器中转换数据
  4. 点击"关闭并上载"将结果导入 Excel

常见转换操作

  • 删除/重命名/移动列
  • 筛选和排序
  • 拆分和合并列
  • 更改数据类型
  • 透视和逆透视
  • 合并和追加查询
