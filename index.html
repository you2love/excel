XLOOKUP 推荐

现代查找函数，替代 VLOOKUP 和 HLOOKUP

=XLOOKUP(lookup_value, lookup_array, return_array, [if_not_found], [match_mode], [search_mode])
  • 支持向左查找
  • 默认精确匹配
  • 可自定义未找到返回值
  • 支持二分查找模式

FILTER 动态数组

根据条件筛选数据区域

=FILTER(array, include, [if_empty])
  • 返回动态数组结果
  • 支持多条件筛选
  • 自动溢出到相邻单元格
  • 可嵌套其他函数

SORT 动态数组

对区域或数组进行排序

=SORT(array, [sort_index], [sort_order], [by_col])
  • 动态排序结果
  • 支持多列排序
  • 升序/降序可选
  • 不改变原始数据

LAMBDA 2021+

创建自定义函数，无需 VBA

=LAMBDA(parameter1, parameter2, ..., calculation)
  • 定义命名函数
  • 支持递归调用
  • 可组合复杂逻辑
  • 提升公式复用性

🚀 LAMBDA 自定义函数示例

使用 LAMBDA 创建可复用的自定义函数，无需 VBA 编程

示例 1：计算圆的面积

=LAMBDA(r, PI() * r^2)

命名为 CIRCLE_AREA 后，可直接使用 =CIRCLE_AREA(5)

示例 2：递归计算阶乘

=LAMBDA(n, IF(n<=1, 1, n * FACTORIAL(n-1)))

命名为 FACTORIAL 后，可计算任意正整数的阶乘

示例 3：多参数复杂计算

=LAMBDA(principal, rate, periods, LET( monthlyRate, rate/12, totalPayments, periods*12, PMT(monthlyRate, totalPayments, -principal) ) )

命名为 CALC_MORTGAGE，计算房贷月供

VBA vs Python 代码对比

VBA 示例：计算销售总额

Sub CalculateTotal()
    Dim ws As Worksheet
    Dim lastRow As Long
    Dim i As Long
    Dim total As Double
    
    Set ws = ThisWorkbook.Sheets("Sales")
    lastRow = ws.Cells(ws.Rows.Count, "A").End(xlUp).Row
    
    total = 0
    For i = 2 To lastRow
        total = total + ws.Cells(i, "C").Value
    Next i
    
    ws.Range("C" & lastRow + 1).Value = total
End Sub

Python 示例：同样的功能

import pandas as pd

# 读取 Excel 数据
df = pd.read_excel("Sales.xlsx", sheet_name="Sales")

# 计算总额
total = df["Amount"].sum()

# 输出结果
print(f"销售总额：{total}")

# 写回 Excel
with pd.ExcelWriter("Sales.xlsx", mode="a") as writer:
    pd.DataFrame({"Total": [total]}).to_excel(writer, sheet_name="Results")

常见错误与解决方案速查表

错误 原因 解决方案 预防方法
#VALUE! 参数类型不匹配 使用 VALUE() 转换文本为数字 数据验证限制输入类型
