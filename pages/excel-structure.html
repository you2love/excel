struct XlsxFile

深入理解 Excel xlsx 文件格式、OpenXML 规范和内部结构

📦 xlsx 文件本质

xlsx 文件本质上是一个 ZIP 压缩包，包含多个 XML 文件和资源文件。理解这个结构对于编程处理 Excel 至关重要。

💡 快速验证

将任何 .xlsx 文件的扩展名改为 .zip，然后解压即可查看内部结构：

mv report.xlsx report.zip unzip report.zip ls -la

📁 文件结构详解

一个典型的 xlsx 文件包含以下目录和文件：

📂 [Content_Types].xml # 包的内容类型定义 📂 _rels/ .rels # 包级别关系 📂 docProps/ app.xml # 应用程序属性 core.xml # 核心属性（作者、创建时间等） 📂 xl/ workbook.xml # 工作簿定义（工作表列表、命名范围等） 📂 _rels/ workbook.xml.rels # 工作簿关系（指向各工作表） 📂 worksheets/ sheet1.xml # 工作表 1 的数据 sheet2.xml # 工作表 2 的数据 sharedStrings.xml # 共享字符串表（所有文本内容） styles.xml # 样式定义（字体、颜色、边框等） theme/theme1.xml # 主题定义 calcChain.xml # 计算链（公式依赖关系）

🔍 核心文件解析

1. [Content_Types].xml

定义包中所有部件的 MIME 类型：

<Types xmlns="http://schemas.openxmlformats.org/package/2006/content-types"> <Default Extension="rels" ContentType="application/vnd.openxmlformats-package.relationships+xml"/> <Default Extension="xml" ContentType="application/xml"/> <Override PartName="/xl/workbook.xml" ContentType="application/vnd.openxmlformats-officedocument.spreadsheetml.sheet.main+xml"/> <Override PartName="/xl/worksheets/sheet1.xml" ContentType="application/vnd.openxmlformats-officedocument.spreadsheetml.worksheet+xml"/> </Types>

2. xl/workbook.xml

定义工作簿结构，包含工作表列表和命名范围：

<workbook xmlns="http://schemas.openxmlformats.org/spreadsheetml/2006/main"> <sheets> <sheet name="Sheet1" sheetId="1" r:id="rId1"/> <sheet name="Sheet2" sheetId="2" r:id="rId2"/> </sheets> <definedNames> <definedName name="MyRange">Sheet1!$A$1:$B$10</definedName> </definedNames> </workbook>

3. xl/worksheets/sheet1.xml

工作表的实际数据，使用稀疏矩阵存储：

<worksheet xmlns="http://schemas.openxmlformats.org/spreadsheetml/2006/main"> <dimension ref="A1:C3"/> <sheetData> <!-- 第 1 行 --> <row r="1"> <c r="A1" t="s"><!-- t="s" 表示共享字符串 --> <v>0</v><!-- 索引 0 指向 sharedStrings.xml 中的字符串 --> </c> <c r="B1"> <v>100</v><!-- 直接存储数值 --> </c> <c r="C1" t="str"><!-- t="str" 表示公式字符串 --> <f>A1*B1</f> <v>100</v> </c> </row> </sheetData> </worksheet>

4. xl/sharedStrings.xml

存储所有文本内容，避免重复：

<sst xmlns="http://schemas.openxmlformats.org/spreadsheetml/2006/main" count=3" uniqueCount="3"> <si> <t>产品名称</t> </si> <si> <t>产品 A</t> </si> <si> <t>产品 B</t> </si> </sst>

单元格中的 <v>0</v> 指向索引 0，即"产品名称"。

5. xl/styles.xml

定义所有样式，单元格通过索引引用：

<styleSheet xmlns="http://schemas.openxmlformats.org/spreadsheetml/2006/main"> <fonts count="2"> <font><!-- 默认字体 --> <sz val="11"/> <name val="Calibri"/> </font> <font><!-- 粗体 --> <b/> <sz val="12"/> </font> </fonts> <fills count="2"> <fill><!-- 无填充 --> <patternFill patternType="none"/> </fill> <fill><!-- 灰色背景 --> <patternFill patternType="solid"> <fgColor rgb="FFCCCCCC"/> </patternFill> </fill> </fills> <cellXfs count="2"> <xf fontId="0" fillId="0"/> <!-- 默认样式 --> <xf fontId="1" fillId="1"/> <!-- 粗体 + 灰色背景 --> </cellXfs> </styleSheet>

💻 编程读取 xlsx

Python - 直接解压读取 XML

import zipfile import xml.etree.ElementTree as ET def read_xlsx_raw(filepath): """直接读取 xlsx 内部 XML 结构""" with zipfile.ZipFile(filepath, 'r') as z: # 读取 sharedStrings.xml with z.open('xl/sharedStrings.xml') as f: tree = ET.parse(f) root = tree.getroot() ns = {'si': 'http://schemas.openxmlformats.org/spreadsheetml/2006/main'} strings = [t.text for t in root.findall('.//si:t', ns)] print(f"共享字符串：{strings}") # 读取 sheet1.xml with z.open('xl/worksheets/sheet1.xml') as f: tree = ET.parse(f) root = tree.getroot() ns = {'x': 'http://schemas.openxmlformats.org/spreadsheetml/2006/main'} for cell in root.findall('.//x:c', ns): ref = cell.get('r') v = cell.find('x:v', ns) print(f"单元格 {ref}: {v.text if v is not None else 'empty'}") read_xlsx_raw('data.xlsx')

Go - 使用 excelize 解析

package main import ( "fmt" "github.com/xuri/excelize/v2" ) func main() { f, err := excelize.OpenFile("data.xlsx") if err != nil { panic(err) } defer f.Close() // 获取所有工作表 sheets := f.GetSheetList() fmt.Println("工作表:", sheets) // 遍历单元格 rows, _ := f.GetRows("Sheet1") for i, row := range rows { for j, col := range row { cell, _ := excelize.CoordinatesToCellName(j+1, i+1) fmt.Printf("%s = %v\n", cell, col) } } }

⚠️ 注意事项

🔒 加密文件

加密的 xlsx 文件无法直接解压，需要先解密。加密信息存储在 xl/encryptionInfo 和 xl/encryptionHeader 中。

📏 大文件处理

xlsx 将整个文件加载到内存中。对于大文件（>100MB），建议使用流式处理：

  • Python: openpyxl 的 read_only=True 模式
  • Go: excelize 的 StreamReader
  • Node.js: exceljs 的流式 API

💡 性能提示

共享字符串表导致文本存储优化，但增加了查找开销。对于纯数值数据，xlsx 文件更小更快。
